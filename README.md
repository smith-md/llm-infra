# llm-ops

Top-level directory for LLM operations tooling and configuration.

Structure:
- `global/` — environment-wide config and shared infra
- `project/` — per-project bootstrapping and memory/backing stores
- `agents/` — agent implementations, orchestration, and runners
- `schemas/` — data schemas (messages, memory entries, config)
- `docs/` — user and developer documentation
